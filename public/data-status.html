    수집 기준

    전국 일일가격
    오피넷 공개 유가내려받기에서 일 1회 수집합니다. 당일 파일이 준비되지 않으면 전일 자료를 사용하며 실제 기준일을 표시합니다.
    지도 좌표
    전국주유소표준데이터와 이전에 확보한 좌표를 결합합니다. 좌표가 확인된 일부 주유소만 지도에 표시합니다.
    자동 갱신
    GitHub Actions 예약 실행으로 갱신합니다. 실행이 지연되거나 수집이 실패하면 마지막 정상 자료와 원래 기준시각을 보존합니다.
