net.softm.juyuhannun · Release 1.1.11 (16) · 2026-11-05

시연 동영상 직접 열기

  1. 사용자가 앱의 레이더 버튼을 누르고 ‘다른 내비 위 2.5D 레이더’를 선택합니다.
  2. 주변 주유소의 방향·거리·가격을 표시하는 투명 레이더가 시작됩니다.
  3. 설정과 홈 등 다른 앱으로 이동해도 위치 기반 주유소 표시가 유지됩니다.
  4. 알림에 레이더 실행 상태와 ‘레이더 끄기’ 버튼이 표시됩니다. 해당 버튼을 누르면 서비스와 오버레이가 종료됩니다. 레이더 화면의 종료 버튼으로도 끌 수 있습니다.

시연 환경: Android 14 (API 34) 테스트 에뮬레이터. 서울시청 부근의 가상 위치를 사용했으며 실제 이용자의 위치나 계정 정보가 포함되지 않았습니다. 설치한 서명된 Release APK를 그대로 녹화했습니다.

위치 포그라운드 서비스는 사용자가 직접 레이더를 시작할 때만 실행됩니다. 레이더는 내비게이션 앱 위에서 주변 주유소의 방향과 거리를 계속 표시하기 위해 위치를 사용합니다. 별도의 ACCESS_BACKGROUND_LOCATION 권한은 요청하지 않습니다. 사용자가 종료하면 위치 갱신도 중단됩니다.
