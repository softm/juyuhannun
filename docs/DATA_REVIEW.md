# 추가 공공데이터 검증과 적용 결정

검토일: 2026-10-20 한국 시각. 첨부 이미지 1개, 오피넷 공공용·민간용 브로셔 각 8쪽, 제공기관의 API 안내 및 공공데이터포털 등록정보를 대조했다. API 키가 없는 상태에서는 명세 검증과 테스트 응답 검증까지만 수행하며, 실운영 가격·충전 상태 검증 완료로 표현하지 않는다.

## 1. 제공받은 자료에서 바로잡은 점

| 입력 자료 | 확인한 실제 범위 | 적용 결정 |
|---|---|---|
| 국내 전국 개별 주유소 판매가격, 파일데이터 15044646 | 포털에서 API 응답을 주는 자료가 아니라 오피넷 다운로드 페이지로 연결하는 일간 CSV 자료 | 전국 초기 적재·과거 분석 후보. 실제 내려받은 파일의 컬럼, 기준일, 인코딩, 주유소 ID를 검증한 뒤 가져와야 한다. 자동 실시간 수집의 대체 경로로 간주하지 않는다. |
| 전국 주유소 평균가격, 15150932 | 주유소별 가격이 아닌 유종별 전국 평균과 전일 증감 | `benchmarks` 데이터로 분리하고 평균 유가 화면에서만 사용한다. |

| 시군구별 주유소 평균가격(현재) | 선택 시도 내 시군구·유종별 평균 | 오피넷 전용 지역코드로 조회한다. 행정구역 코드나 충전 API의 지역코드를 그대로 넣지 않는다. |
| 충전소 정보로 받은 15145097 | **한국석유관리원 수소충전소별 월평균 판매가격**. 시간 범위는 직전월이다. | 수소 참고 화면으로 분리. 전기차 충전소·충전기 가동 상태·당일 판매가격으로 사용하지 않는다. |
| 한국도로공사 0312 | 고속도로 휴게소 주유소 가격 및 업체 현황 | 공급자 ID·노선·방향을 보존하는 별도 조회 화면과 어댑터. 오피넷 시설과 이름만으로 병합하지 않는다. |

공공데이터포털의 `업데이트 주기: 실시간`은 자료 내용의 시간 단위를 대신하지 않는다. 예를 들어 15145097은 이 메타데이터가 있어도 **직전월 평균**이다. 갱신 가능 빈도, 앱 수집 시각, 원본 가격·상태 기준시각, 집계 기간을 각각 기록해야 한다.

## 2. 오피넷 브로셔 확인 결과

공공용과 민간용의 일반 API 목록 및 신청 절차는 일치한다. 전체 22종 중 일반 19종은 기본 300회/일이며, 1,500회/일의 일반 API 이용에는 기업·기관 제휴가 필요하다. 전국 전체 주유소 기본정보, 변경정보, 판매가격의 3종은 프리미엄 API 범위다. 일부 공공기관·소상공인·창업기업 등은 제휴를 통한 무료 지원 대상이 될 수 있지만, 이 앱이 자동으로 해당 자격을 취득하는 것은 아니다. 프리미엄 호출은 등록 서버 IP를 사용하고, 안내상 키당 최대 3개 IP까지 등록한다.

이에 따라 기본 앱은 다음처럼 구성한다.

1. 반경 검색으로 후보를 받고, 제한된 수의 상세정보 조회로 유종별 보고시각을 확인한다.
2. 동일 요청·상세정보·평균가격은 캐시와 동시 요청 합치기로 공유한다.
3. 서버 및 수집기는 한국 시각 기준 일일 호출 원장을 사용한다.
4. 전국·시도 평균은 각각 한 번에 받아 유종 변경 시 추가 호출을 줄인다.
5. Pages 기본 수집 지역은 서울시청·대전역 주변으로 명시한다. 무료 일반 API만으로 전국 완전 수집이 된 것처럼 표시하지 않는다.
6. 전국 전환은 프리미엄 제휴 조건과 고정 출구 IP를 가진 수집 서버를 먼저 마련해야 한다. GitHub Actions의 일반 실행기를 등록 IP 서버로 간주하지 않는다.

브로셔에 있는 절약 효과 홍보 수치는 운행거리·연비·주유량 등의 조건이 없어 앱의 개인별 실제 절약액으로 채택하지 않았다. 사용자 입력과 확인된 가격·경로로 계산한 예상 금액만 표시한다.

## 3. 앱의 데이터 계약

| 데이터 | 값의 의미 | 시간 | 위치·가격 추천 처리 |
|---|---|---|---|
| 오피넷 주유소 | 선택 유종의 개별 판매가격, 원/L | `priceUpdatedAt`와 `fetchedAt` 분리 | 보고시각 미확인·24시간 초과는 기본 추천에서 제외 |
| 고속도로 주유소 | 도로공사 제공 유종별 가격·운영 정보 | 원본에 시각이 없으면 `priceUpdatedAt: null` | 검증된 좌표가 있을 때만 지도 표시. 방향을 포함해 표시 |
| 평균 유가 | 전국·시도·시군구의 평균, 원/L | 날짜만 있으면 `asOfDate`; 없는 날짜는 null | `benchmarks` 배열 사용. 시설 목록과 자동 절약액 계산에 넣지 않음 |
| 전기차 충전기 | 기기별 충전 상태·출력·방식 | 상태 변경시각과 조회시각을 분리 | 최근 조회의 응답 상태로 표현. 예약 가능·도착시 이용 가능을 보장하지 않음 |
| 수소 월평균 | 직전월의 충전소별 평균 | 기준연월 | 당일 주유 가격과 순위를 합치지 않음 |

전기차 충전 요금은 충전기 상태 정보와 별개의 계약이다. 회원·비회원·로밍 사업자·시간대 등의 요금 조건이 검증되지 않으면 원/kWh 금액을 만들지 않는다. 주유용 km/L와 충전용 kWh를 같은 절약식에 대입하지 않는다.

## 4. 공개 정적 화면과 조회 서버

Pages에는 키가 없는 공개 JSON만 배포한다. 원본 API 키는 서버 환경 또는 GitHub Actions Secret에서 읽는다. 새로고침과 페이지 빌드 시각으로 기존 자료의 기준시각을 덮어쓰지 않는다. 수집에 실패하면 이전 자료의 원래 시각을 유지하고 실패 상태를 표시한다.

충전기 상태처럼 짧은 시간에 달라지는 값은 하루 몇 번 갱신되는 Pages 수집만으로 현재 상태라고 표시할 수 없다. 최신 상태를 계속 조회하려면 별도 API 서버가 필요하다. 화면은 오래된 조회 결과의 `충전대기` 수를 현재 이용 가능한 수처럼 보여주지 않는다.

## 5. 개통 전 확인할 실제 데이터

- 발급된 각 API 키로 정상 응답·인증 오류·호출량 초과를 확인한다.
- 오피넷 선택 주유소의 표시가격·유종·기준시각을 같은 시각의 원본과 대조한다.
- 고속도로 자료의 응답 페이지 수, 노선·상하행·LPG 여부, 좌표 결합 근거를 확인한다.
- 충전기 API의 지역별 페이지 수, 중복 기기 ID, 운영 중단·통신 이상·조회 지연을 확인한다.
- 평균가격의 소수점, 전국 날짜와 시도 날짜 미제공, 전일 증감 부호를 확인한다.
- 각 조회 오류에서 오래된 값이 최신값으로 바뀌지 않는지 확인한다.

현재 테스트는 계산·정규화·오류 처리의 재현 가능한 계약을 검증한다. 외부 운영계 응답의 최신성이나 현장 계기판 정확성을 보장하는 검사는 아니다.
