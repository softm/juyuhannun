## 노출 동작

광고는 주유소 상세를 실제로 연 뒤 상세 패널 하단 지면이 화면에 접근하고 규격 너비가 확보됐을 때 한 번 요청한다. 상세 데이터 갱신으로 패널을 다시 그리더라도 이미 요청한 광고 DOM과 iframe을 다시 만들지 않는다. PC·모바일 규격이 바뀌면 해당 규격 전용 단위를 사용한다.

운영 주소가 아닌 로컬·미리보기 환경, 320px 또는 728px 규격보다 좁은 컨테이너, 문서 비가시 상태, SDK 오류, 10초 이내 프레임 미생성, NOAD 응답에서는 광고와 빈 공간을 숨긴다. WebView User-Agent에 `AdMobNative/1`이 있으면 네이티브 AdMob과 중복되지 않도록 웹 AdFit을 요청하지 않는다.

## 검증

배포 후 PC와 모바일에서 각각 주유소 상세를 열고 다음을 확인한다.

1. 상세 하단의 `광고` 라벨 아래에 해당 규격 광고가 표시되는가.
2. 상세 탭 전환, 가격 갱신, 다른 주유소 선택에서 같은 단위를 반복 요청하지 않는가.
3. 광고 차단·NOAD·느린 네트워크에서 빈 여백이 남지 않는가.
4. 모바일 상세 패널의 길안내·공유·찜 버튼과 광고가 겹치지 않는가.
5. Android 네이티브 광고 앱에서 웹 광고가 함께 표시되지 않는가.

실제 송출은 AdFit의 매체 심사, 광고 재고와 클라이언트 환경에 따라 달라질 수 있다.
